# BaristaOne Docs

Bu klasör BaristaOne projesinin uzun vadeli planlarını içerir.

## Dosyalar

- `ROADMAP.md`: Projenin sürüm bazlı gelişim planı.
- `ARCHITECTURE.md`: Mevcut ve hedef teknik mimari.
- `DEVOPS_PLAN.md`: Docker, Redis, RabbitMQ, CI/CD ve test altyapısı planı.
- `MOBILE_PLAN.md`: React Native / Expo ile mobil uygulama geliştirme planı.

## Genel Hedef

BaristaOne projesini ders projesinden çıkarıp profesyonel, ölçeklenebilir, web + mobil destekli gerçek bir kafe operasyon sistemine dönüştürmek.
